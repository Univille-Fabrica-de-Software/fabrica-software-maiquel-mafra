# Landing Page - Panorama do Mercado Tech

## Descrição
Este projeto é uma landing page acadêmica desenvolvida para apresentar um panorama inicial do mercado de tecnologia. O sistema organiza informações sobre vagas locais e nacionais, destacando requisitos, linguagens, frameworks e competências exigidas pelo mercado de trabalho. Atividade desenvolvida para a disciplina de Fábrica de Software da Univille.

## Tecnologias utilizadas
- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
- GitHub Pages

## Estrutura do Projeto
O projeto foi organizado com foco em sustentabilidade e clareza:
- `index.html`: Arquivo principal contendo a estrutura visual da página.
- `assets/`: Diretório para arquivos estáticos, como imagens e ícones.
- `css/`: Diretório para a folha de estilo customizada (`style.css`).
- `docs/`: Diretório dedicado à documentação técnica do projeto (Visão Geral, Requisitos, Decisões de Layout e Registro de Testes).

## Como executar
Abra o arquivo `index.html` no navegador ou utilize a extensão Live Server.
