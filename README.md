# Landing Page - Panorama do Mercado Tech

## Acadêmico
Maiquel Robert Mafra Junior

## Objetivo
Apresentar um resumo das vagas locais (Joinville e Região) e nacionais (Remoto) pesquisadas na disciplina de Fábrica de Software.

## Tecnologias Utilizadas
- HTML5
- CSS3

## Principais Percepções
Durante o levantamento de vagas, observou-se que o mercado regional de Joinville e Santa Catarina possui forte demanda pelo ecossistema corporativo tradicional, focado em linguagens como C# (.NET) e Java, acompanhadas de bancos de dados relacionais como SQL Server e PostgreSQL. 

Já no mercado nacional (remoto), percebeu-se que a régua técnica é mais elevada: além do domínio das linguagens e orientação a objetos, as vagas cobram conhecimentos antecipados em infraestrutura, como conteinerização via Docker, ambientes em nuvem (AWS/Azure) e testes automatizados. O controle de versão com Git/GitHub mostrou-se um requisito 100% indispensável em todas as vagas analisadas.
