# 01 - Visão Geral do Projeto

## 1. Contexto e Problema
As informações sobre vagas de tecnologia costumam estar distribuídas em diferentes plataformas e fontes. Para estudantes em formação, essa dispersão dificulta a percepção sobre quais competências são mais exigidas e quais tecnologias merecem atenção durante o percurso acadêmico.

## 2. Objetivo
O projeto propõe organizar parte desse levantamento em uma landing page, permitindo que o visitante compreenda rapidamente o panorama observado.

## 3. Público-alvo
Estudantes em formação na área de tecnologia.

## 4. Escopo e Funcionalidades Principais
O projeto consiste em uma página única (*single-page*) focada em apresentação informacional estruturada nas seguintes funcionalidades:
* Apresentar uma introdução sobre o panorama do mercado de tecnologia.
* Exibir resumo da pesquisa realizada.
* Listar vagas locais e nacionais com informações essenciais organizadas em *cards*.
* Apresentar as tecnologias mais citadas por meio de *badges* visuais.
* Apresentar competências técnicas e comportamentais.
* Exibir uma análise final sobre as exigências do mercado.
* Permitir navegação interna fluida por meio de um menu superior.
* Preparar a estrutura base do front-end para futura integração de dados via API.

## 5. Tecnologias e Organização
* **HTML5 e CSS3:** Para a estruturação semântica e regras visuais próprias.
* **Bootstrap 5:** Para o sistema de grid, botões e componentes responsivos.
* **Arquitetura:** Separação limpa entre a raiz (`index.html`) e diretórios de recursos (`assets/`, `css/` e `docs/`).
* **Deploy:** Versionado através do Git e hospedado como página estática via GitHub Pages.
