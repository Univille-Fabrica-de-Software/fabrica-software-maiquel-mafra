# Visão Geral do Projeto

## Nome do projeto

Landing Page - Panorama do Mercado Tech

## Contexto

Este projeto foi desenvolvido na disciplina de Fábrica de Software com o objetivo de apresentar um panorama inicial do mercado de tecnologia.

A proposta parte da análise de vagas locais e nacionais da área de tecnologia, observando cargos, tecnologias solicitadas, competências técnicas, competências comportamentais e tendências percebidas no mercado.

A landing page organiza essas informações em uma página web simples, responsiva e de fácil leitura.

## Problema

As informações sobre o mercado de tecnologia geralmente estão distribuídas em diferentes plataformas de vagas, sites de empresas e redes profissionais.

Para estudantes em formação, essa dispersão pode dificultar a compreensão sobre:

- quais cargos aparecem com mais frequência;
- quais tecnologias são mais exigidas;
- quais competências comportamentais são valorizadas;
- quais diferenças existem entre vagas locais e nacionais;
- quais conhecimentos devem ser priorizados durante a formação acadêmica.

## Objetivo geral

Desenvolver uma landing page responsiva para apresentar, de forma organizada e objetiva, uma análise inicial de vagas da área de tecnologia.

## Objetivos específicos

- Organizar informações sobre vagas locais e nacionais.
- Identificar tecnologias recorrentes nas vagas analisadas.
- Apresentar competências técnicas e comportamentais observadas.
- Aplicar HTML, CSS e Bootstrap na construção da interface.
- Utilizar estrutura de arquivos organizada.
- Versionar o projeto com Git e GitHub.
- Documentar decisões e testes realizados.
- Preparar o projeto para futura integração com uma API back-end.

## Público-alvo

O público-alvo da página é composto por:

- acadêmicos da disciplina de Fábrica de Software;
- professores;
- estudantes interessados no mercado de tecnologia;
- pessoas que desejam compreender tendências básicas de vagas na área.

## Escopo da primeira versão

Nesta primeira versão, a página apresenta dados fixos diretamente no HTML.

O projeto contempla:

- página inicial responsiva;
- cabeçalho com logo e menu de navegação;
- apresentação da pesquisa;
- cards de vagas locais;
- cards de vagas nacionais;
- lista de tecnologias mais citadas;
- competências técnicas e comportamentais;
- análise final;
- rodapé;
- documentação inicial;
- publicação futura com GitHub Pages.

## Fora do escopo da primeira versão

Nesta etapa, o projeto ainda não contempla:

- cadastro de vagas por formulário;
- integração com banco de dados;
- consumo de API;
- autenticação de usuários;
- painel administrativo;
- filtros dinâmicos;
- busca por tecnologia ou cargo;
- uso de JavaScript próprio.

Esses recursos poderão ser implementados em etapas futuras da disciplina.

## Tecnologias utilizadas

- HTML5
- CSS3
- Bootstrap 5
- Git
- GitHub
- GitHub Pages

## Relação com as próximas etapas

Este projeto representa a camada inicial de front-end.

Nas próximas etapas da disciplina, a landing page poderá evoluir para consumir dados fornecidos por uma API desenvolvida com Java e Spring Boot.

A evolução prevista é:

```text
Front-end estático
↓
Front-end organizado e versionado
↓
Back-end com Java e Spring Boot
↓
Banco de dados
↓
Integração front-end + back-end
↓
Projeto completo
```
