# 02. Requisitos do Sistema

## Requisitos Funcionais (RF)
| Código | Requisito Funcional | Descrição |
| :--- | :--- | :--- |
| **RF01** | Exibir Cabeçalho | Apresentar barra de navegação superior com logotipo e links internos de rolagem. |
| **RF02** | Apresentar Hero Section | Exibir mensagem principal de conscientização, imagem e botão de chamada. |
| **RF03** | Conceituar Bullying | Descrever a definição básica e os 3 critérios: intencionalidade, repetição e desequilíbrio. |
| **RF04** | Apresentar Tipos de Bullying | Listar em cards os tipos: Verbal, Físico, Social e Cyberbullying. |
| **RF05** | Destacar Cyberbullying | Apresentar seção informativa destacando os impactos do ambiente digital. |
| **RF06** | Exibir Sinais de Alerta | Listar indícios visíveis de isolamento, queda de rendimento e mudanças de comportamento. |
| **RF07** | Indicar Ações e Canais de Apoio | Exibir orientações seguras de como agir e contatos públicos e gratuitos de apoio (Disque 100, CVV 188 e Equipe Escolar). |
| **RF08** | Exibir Compromisso da Comunidade | Apresentar uma seção de apelo e conscientização sobre o compromisso da comunidade. |
| **RF09** | Exibir Rodapé | Apresentar identificação acadêmica, disciplina, universidade e ano. |

## Requisitos Não Funcionais (RNF)
| Código | Requisito Não Funcional | Descrição |
| :--- | :--- | :--- |
| **RNF01** | Responsividade | O layout deve adaptar-se perfeitamente a celulares, tablets e desktops via Bootstrap 5. |
| **RNF02** | Estrutura e Organização | O código deve seguir a estrutura de pastas padronizada (`assets/`, `css/`, `docs/`). |
| **RNF03** | Semântica HTML5 | Utilização correta de tags estruturais (`<header>`, `<main>`, `<section>`, `<footer>`). |
| **RNF04** | Acessibilidade e SEO | Incluir metadados no `<head>`, atributo `lang="pt-BR"` e `alt` descritivo em todas as imagens. |
| **RNF05** | Caminhos Relativos | Referenciar arquivos internos sempre por caminhos relativos sem barra inicial. |
| **RNF06** | Versionamento e Publicação| Projeto versionado com Git, hospedado no GitHub e publicado no GitHub Pages. |
| **RNF07** | Privacidade e Segurança Ética | O projeto não deve coletar dados pessoais sensíveis, relatos reais ou possuir formulários de denúncia funcionais. |
